# Herzweg24 Website

Prototypen der neuen Startseite für Betreuungsdienst Herzweg24.

- `index.html`: Übersicht der drei Entwürfe
- `entwurf-a.html`, `entwurf-b.html`, `entwurf-c.html`: Startseite in drei Gestaltungen (erzeugt mit `python3 tools/build_entwuerfe.py`)
- `assets/`: CSS, Schriften, Icons, Logo, Fotos (lizenziert über Magnific, ohne Wasserzeichen)
