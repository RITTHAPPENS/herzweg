# Herzweg24 Website

Prototyp der neuen Website für Betreuungsdienst Herzweg24 (herzweg24.de).

- `index.html`: Startseite
- `assets/`: CSS, Schriften, Icons, Logo
- `PRODUCT.md`: Produkt- und Kundenfakten
- `DESIGN.md`: Designsystem

Lokal ansehen: `index.html` im Browser öffnen. Die Stockfotos werden aktuell direkt von Magnific geladen und sind Platzhalter, die Teamfotos folgen.
